# 🔒 Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security issue or vulnerability in Deskstamp:

1. Please do **not** open a public issue.
2. Email the maintainer directly at **gabrielngama@gmail.com** with details and reproduction steps.
3. We will acknowledge receipt within 48 hours and work on a prompt fix.
